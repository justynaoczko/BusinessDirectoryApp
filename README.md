# Katalog Firm / Wizytówki Biznesowe

## Opis projektu

Aplikacja webowa do przeglądania katalogu firm oraz zarządzania wizytówkami biznesowymi poprzez panel administracyjny.

## Funkcjonalności

* Lista firm
* Wyszukiwarka
* Kategorie firm
* Wizytówki firm
* Panel administracyjny
* Logowanie administratora

## Technologie

Frontend:

* HTML
* CSS
* JavaScript / React

Backend:

* ASP.NET Core MVC
* Entity Framework
* SQL Server
